# Fonts

The app's three families, compiled into the binary (`src/fonts.rs`). Each is the variable font, upright and italic, from the `ofl/` folders of [google/fonts](https://github.com/google/fonts) at commit `6ebe737e44fd64ee736bbc6feed6136a6dbfd222` (2026-11-25), unchanged, under the SIL Open Font License 1.1 in the `OFL.txt` beside it.

| Family | Use |
|---|---|
| Instrument Sans | The interface: bars, menus, the status line |
| Literata | The writing |
| JetBrains Mono | Code in the writing |
