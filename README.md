### WARREN

Write words on a page. Where a part should look a certain way, open a block and say so in your own words. Warren picks a real part from a catalog that a person designed, fills in its settings, and shows the page as you type. The site's look is picked the same way, from a line at the root.

```markdown
::: a quote from the book, big and centred

Not all those who wander are lost.

:::
```

You write the page. The model never does. Blogs first.

Nothing is built yet. The plan is in [docs/plan.md](docs/plan.md).
