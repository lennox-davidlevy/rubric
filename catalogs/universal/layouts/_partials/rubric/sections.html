{{- /* Splits a part's rendered Markdown at one heading level, for parts made of titled pieces: cards, steps, a timeline, pricing, tabs, a fold of several questions. Returns a dict: "before" (what comes ahead of the first heading) and "items", each with "title" (HTML), "id" and "body" (HTML). Headings of a part placed inside this one (marked data-in-part by rubric/draw.html) are left where they are: a recipe card in a carousel's slide keeps its "### Ingredients", and the slide stays one slide. A block with no such headings of its own makes each part placed in it an item, whose title is empty; a part that needs a title on each item (tabs, fold, pricing) passes "parts" false. Usage: {{ $x := partial "rubric/sections.html" (dict "html" .inner "level" 3) }} */ -}} {{- $tag := printf "h%d" .level -}} {{- $nested := printf "<%s data-in-part" $tag -}} {{- $hidden := "]*>(.*?).*$` $tag) "$1" .) $hidden $nested -}} {{- $id := replaceRE `(?s)^\s*id="([^"]*)".*$` "$1" . -}} {{- if eq $id . }}{{ $id = "" }}{{ end -}} {{- $body := replace (replaceRE (printf `(?s)^[^>]*>.*?` $tag) "" .) $hidden $nested -}} {{- $items = $items | append (dict "title" ($title | safeHTML) "id" $id "body" ($body | safeHTML)) -}} {{- end -}} {{- $before := replace (index $chunks 0) $hidden $nested -}} {{- /* A block with no headings of its own, holding parts placed straight in it (two recipe cards in a carousel): each part is an item, with no title. draw.html marks where each part it holds starts and ends. */ -}} {{- $byPart := cond (isset . "parts") .parts true -}} {{- if and (not $items) $byPart -}} {{- $parts := findRE `(?s).*?` $before -}} {{- range $parts -}} {{- $items = $items | append (dict "title" "" "id" "" "body" (. | safeHTML)) -}} {{- $before = replace $before . "" -}} {{- end -}} {{- if $parts }}{{ $before = trim $before " \n" }}{{ end -}} {{- end -}} {{- return dict "before" ($before | safeHTML) "items" $items -}}
